# Maud

Maud is an extension for Claude Code. It's a project management framework, inspired by the GSD framework, but adapted to fit my own personal brand of doing project management for software (and other project) project management. It's all local, uses human readable markdown files and is highly extensible and adaptable on a per project basis. It has meta-introspection to make your life easier.

Whereas GSD generates a .planning/ dir for your project, maud generates a .maud. Everything that is Maud is contained within this file.

I've created the very first .maud/ dir, the one you find in this very project, I crafted it by hand. I'm bringing GSD into the mix so I can actually build out the plugin that can execute the project outlined in the .maud/ dir I've created. Does that make sense? It's hard to explain because it's almost like AI metaprogramming.

Basically I just want you to complete all of the stories in the backlog in the .maud/stories/index.md, each one a phase.

No need to do research or figure out the structure, I've already outlined it all in the .maud file. Let's just do all the stories in the backlog, each one a phase. The last two, that link to sub-directories, those have many sub-tasks, so each one of those should be its own phase too.
