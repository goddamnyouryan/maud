Maud doesn't have a "design" per se, as it is just a claude code plugin, so it's just a few /slash commands and then normal AI interaction in the claude code chat window.

The slash commands:

/maud:plan Runs the entire planning process, generates a .maud file for that project.
/maud:build Takes the next story off of the top of the backlog and starts working on it
/maud:help Tells you how the other commands work
