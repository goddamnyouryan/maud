# Maud

Maud is project management that just makes sense.

## How to Use
Install the Maud Plugin into your Claude Code.

Run `/maud:plan`

This generates your .maud directory. Once that's complete, you can run:

`/maud:build`

And Maud will start building your project. Keep doing `/maud:build` until your done.

At any point, if you want to change how the project is structured, or what its goals are, you can talk to maud, or just change any of the files in the .maud folder directly
